# PurrLCD Editor

Редактор Compose Desktop запускается отдельно от C++-движка. Закрытие окна полностью завершает JVM; фоновый движок и экран продолжают работу.

## Сборка

Требуется Java 21. Gradle 9.6 загружается комплектным wrapper при первой сборке. Из этой папки:

```powershell
.\gradlew.bat --gradle-user-home ../.work/editor-build/gradle-home --project-cache-dir ../.work/editor-build/project-cache test createDistributable
```

Портативная сборка появляется в папке относительно корня проекта: `.work/editor-build/build/compose/binaries/main/app/PurrLCDEditor`. Она включает Java runtime. На машине пользователя Java не нужна.

Запуск редактора:

```powershell
PurrLCDEditor.exe --engine "C:\path\engine\PurrLCD.exe" --data "C:\path\data"
```

Без аргументов движок ищется рядом с папкой редактора в `engine/PurrLCD.exe`, данные — в соседней папке `data`. `--no-engine-start` отключает запуск движка (для проверки редактора). Команда соединения с физическим экраном отправляется только кнопкой пользователя.

## Интерфейс

- «Экран»: предпросмотр 720 × 720, подключение/отключение и реальные показатели.
- «Редактор»: фон, слои CPU/GPU, координаты, размер, подпись, цвет и видимость.
- «Настройки»: частота обновления и поворот экрана.
- «Применить»: сохранение сцены в движке; изменения предпросмотра сами по себе не сохраняют сцену.

IPC использует именованный канал Windows `PurrLCD-<имя пользователя>`. Каждый запрос — отдельное подключение, 4-байтовая длина little-endian, затем UTF-8 JSON (до 1 МиБ). До начала передачи повторяется только открытие занятого канала, максимум 500 мс. Тайм-аут запроса — 3 секунды: зависшее синхронное чтение Windows изолировано в единственном daemon-потоке и не блокирует интерфейс или завершение JVM. Опрос состояния работает только пока редактор открыт; генерация предпросмотра происходит при изменении сцены с задержкой 250 мс или изменении показанной температуры.

Два теста используют отдельный временный канал Windows, без доступа к физическому экрану: проверка framing/JSON и зависшего сервера с тайм-аутом и неблокирующим закрытием.
